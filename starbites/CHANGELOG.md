Part 3 - Enhancing Website Functionality and SEO

1. Existing Website Improvements

* Continued working with the existing Star Bites website from Parts 1 and 2.
* Kept the five main website pages: Home, About Us, Products, Enquiries and Contact.
* Retained the existing cream and dark brown colour scheme.
* Kept the existing external stylesheet named styles.css.
* Maintained the existing business information, navigation structure and product details.
* Improved the website to support desktop, tablet and mobile screen sizes.

2. JavaScript Functionality

* Created the external JavaScript file named apps.js.
* Added a product catalogue to manage and display product information.
* Added a search feature to help customers find products.
* Added category filtering to organise products.
* Added sorting options to arrange products by name or price.
* Added an image lightbox to display larger product images.
* Added interactive tabs to the About Us page.
* Added an FAQ accordion to the Home page.
* Added an enquiry price estimate that updates according to the selected product and quantity.

3. Forms and Validation

* Improved the product and service enquiry form.
* Added a separate general contact form.
* Included customer information fields such as name, email address, phone number and message.
* Added HTML form validation and JavaScript validation.
* Added feedback messages for successful submissions and errors.
* Integrated the FormSubmit AJAX service to process form submissions.
* Configured the recipient email address in apps.js.

4. Search Engine Optimisation (SEO)

* Added page-specific titles and meta descriptions.
* Included relevant keywords for the website pages.
* Improved image alternative text to describe website images.
* Maintained a clear heading structure.
* Added internal links between the website pages.
* Created a robots.txt file.
* Created a sitemap.xml file to help search engines discover the website pages.

5. Performance and Security

* Added lazy loading to product images.
* Used external CSS and JavaScript files to organise the website code.
* Added input requirements and character limits to forms.
* Used JavaScript to validate customer information.
* Handled form information without inserting user input directly as HTML.
* Included security attributes on external links that open in new tabs.
* Added support for reduced-motion preferences.
* Prepared the website for HTTPS hosting.

6. Responsive Design

* Improved the existing CSS to support different screen sizes.
* Added responsive layouts for desktop, tablet and mobile devices.

* Used a 600px breakpoint for mobile layouts.
